# homebrew-lumen

Homebrew tap for [Lumen](https://github.com/faisalmumtaz89/Lumen), the GPU-resident LLM inference engine for Apple Silicon (Metal).

```bash
brew tap faisalmumtaz89/lumen
brew install lumen
```

`Formula/lumen.rb` is the `lumen.rb` attached to each GitHub Release of Lumen; it is regenerated by Lumen's release workflow with the shipped tarball's URL, version and sha256, and copied here once per release.
